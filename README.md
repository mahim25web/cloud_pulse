# CloudPulse

**CloudPulse** is a modern web application built to monitor and manage cloud infrastructure efficiently.

## 🚀 Live Demo
Check out the live application: [cloudpulse-phi.vercel.app](https://cloudpulse-phi.vercel.app)

## 🛠️ Tech Stack
This project is built using modern web technologies:
* **TypeScript** (~81.3%) — For robust, typed application logic and components.
* **CSS** (~18.7%) — For styling and responsive user interfaces.

## 📂 Project Structure

* `public/` — Static assets and public resources.
